# Digital Image Processing (PCD) Project — Group 2

## Project Topic

**Illegal Parking Detection and Enforcement Route Prioritization**

This project proposes a system that uses digital image processing to identify possible illegal parking from video footage. A tabular Q-learning model will then recommend which flagged location an enforcement officer should inspect next.

The system is designed to recommend inspections. It does not automatically determine whether a driver has broken a parking rule. No deep learning will be used.

## Project Status

**Proposal stage.** The video source has not been finalized, and no footage has been processed or experimental results produced yet.
